# Starting in Python — Fase 1, Imersão Python (Alura)

Anotações e exercícios práticos da **Fase 1 da Imersão Python da Alura**, cobrindo os fundamentos da linguagem e uma primeira introdução à análise de dados com pandas.

## 📚 Conteúdo das aulas

| Aula | Tópicos |
|---|---|
| Aula 1 | Listas, indexação, `for` sobre listas, formatação de strings com f-string |
| Aula 2 | `for` com `range()`, pareamento de listas por posição, introdução ao pandas (`DataFrame`, exportação para Excel) |
| Aula 3 | `while`, validação de entrada do usuário (`input`), operadores lógicos, listas de valores válidos |
| Aula 4 | Pandas: leitura de Excel (`read_excel`), filtragem de dados, agrupamento (`groupby`), estatísticas descritivas (média), visualização com `matplotlib` |

## 🛠️ Tecnologias

- **Python 3**
- **pandas** — manipulação e análise de dados
- **matplotlib** — visualização de dados
